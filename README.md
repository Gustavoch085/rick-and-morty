# Catálogo Rick and Morty

Atividade de React + Next.js com componentes reutilizáveis e dados estáticos.

O projeto está na pasta [`atividade-rick-morty`](./atividade-rick-morty).

## Baixar e executar

1. Baixe o arquivo `atividade-rick-morty.zip`
2. Extraia com WinRAR (ou outro descompactador)
3. No terminal, dentro da pasta extraída:

```bash
cd atividade-rick-morty
npm install
npm run dev
```

4. Abra [http://localhost:3000](http://localhost:3000)
